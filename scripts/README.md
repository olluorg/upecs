# Генерация озвучки карточек (fallback TTS)

На части устройств `window.speechSynthesis` не работает (нет голосов, отключён,
баги Android/iOS/Linux). Чтобы озвучка работала везде, мы заранее генерируем
MP3-файлы для всех карточек и кладём их в репозиторий. Приложение сначала
пытается проиграть готовый MP3 и только при его отсутствии откатывается на
системный синтез речи.

## Что генерируется

- `public/audio/ru/<id>.mp3` и `public/audio/en/<id>.mp3` — по одному файлу на карточку.
- `public/audio/manifest.json` — список озвученных карточек по языкам (читает приложение).

`<id>` — это `id` карточки из `src/data/cards.json`. Подписи берутся из
`src/locales/ru.ts` / `en.ts` (та же логика, что в приложении).

## Движок

[Silero TTS](https://github.com/snakers4/silero-models) — нейросетевой синтез:
качественный русский, расстановка ударений/ё, свободная лицензия, быстрый.
Это **синтез речи (text → audio)**, а не Whisper (тот наоборот — распознавание).

Голоса по умолчанию: русский — `baya` (женский), английский — `en_0`.

## Запуск

На машине с Python 3.9+ (GPU не обязателен, но ускоряет — RTX 3090 и т.п.):

```bash
python scripts/generate_audio.py
```

Скрипт **автономен**: при первом запуске сам создаёт `scripts/.venv`, ставит
зависимости (torch, numpy, lameenc) и перезапускается внутри окружения.
Затем скачивает модели Silero (один раз, кешируются) и генерирует все файлы.

Повторные запуски пропускают уже существующие MP3 — будут озвучены только
новые карточки. После прогона закоммитьте новые файлы:

```bash
git add public/audio
git commit -m "Добавлена озвучка карточек"
```

## Флаги

| Флаг | По умолчанию | Описание |
|------|--------------|----------|
| `--langs ru,en` | `ru,en` | Какие языки генерировать |
| `--force` | — | Перегенерировать даже существующие файлы |
| `--ru-speaker` | `baya` | Голос RU: `baya`, `kseniya`, `xenia`, `aidar`, `eugene` |
| `--en-speaker` | `en_0` | Голос EN: `en_0` … `en_117` |
| `--sample-rate` | `24000` | Частота: `8000`/`24000`/`48000` |
| `--bitrate` | `64` | Битрейт MP3, кбит/с |
| `--limit N` | `0` (все) | Сгенерировать только первые N карточек (для проверки) |

Быстрая проверка перед полным прогоном:

```bash
python scripts/generate_audio.py --limit 3
```

## GPU (CUDA)

По умолчанию ставится обычный `torch`. Если `torch.cuda.is_available()`, GPU
используется автоматически. Чтобы поставить именно CUDA-сборку torch:

```bash
TORCH_INDEX_URL=https://download.pytorch.org/whl/cu121 python scripts/generate_audio.py
```

(Объём небольшой — 934 коротких слова Silero синтезирует за секунды на GPU
и за пару минут на CPU, так что GPU не критичен.)
